# dictation

TOEFL 딕테이션 (학생 페이지 `index.html`, 관리자 페이지 `admin.html`).

이 저장소에는 화면 코드만 있다. 문장·정답은 선생님의 구글 시트 「문제」 탭에, 음성은 선생님 구글 드라이브의 「딕테이션 음원」 폴더(세트마다 `<테스트 id>_<세트 id>.json` 하나)에 있고,
입장 코드를 넣은 학생에게만 구글 쪽 서버(`apps-script/Code.gs`)가 꺼내 보낸다. 채점도 서버에서 한다.

학생은 기간 → 반 → 이름 → 입장 코드로 들어온다. 새 책은 관리자 페이지 「설정」 탭에서 문제 파일(JSON)과 음성 폴더를 올린다. 문제·음성 파일은 저장소에 올리지 않는다.
